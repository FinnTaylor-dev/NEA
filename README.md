NEA is an open source, privacy first calorie tracker for desktop. Built for simplicity, performance, and developer experience.

<!-- DOCUMENTATION_SECTION -->

## 🚀 Features

- **Core Capability**: Barcode lookup
- **Reliable & Fast**: Text input — type food descriptions

## 📦 Installation

```bash
# Create the virtual environment (.venv is recommended)
python3 -m venv .venv   # or `python -m venv .venv` depending on your system

# Activate the venv
source .venv/bin/activate

python3 -m pip install -r requirements.txt

python3 app.py
```
